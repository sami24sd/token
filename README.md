# 🎓 ربات اتوماسیون آموزشی مدرسه

یک ربات تلگرامی سبک برای مدرسه‌ها که به‌صورت خودکار برنامهٔ درسی، تکالیف،
آزمون تمرینی و گزارش‌های مدیریتی را به دانش‌آموزان و مدیران ارسال می‌کند.

نوشته‌شده تنها با **کتابخانهٔ استاندارد پایتون** — بدون هیچ وابستگی بیرونی.

---

## ✨ قابلیت‌ها

### برای دانش‌آموز
| دستور | کارکرد |
|---|---|
| `/start` | ثبت‌نام (نام و پایه) |
| `/today` | برنامهٔ امروز + تکالیف سررسید |
| `/week` | برنامهٔ کل هفته |
| `/homework` | تکالیف فعال |
| `/grades` | نمرات |
| `/average` | معدل |
| `/quiz [درس]` | آزمون تمرینی با دکمه‌های شیشه‌ای |
| `/score` | کارنامهٔ آزمون‌ها |
| `/profile` / `/mystats` | پروفایل و آمار |

### برای مدیر مدرسه
| دستور | کارکرد |
|---|---|
| `/addlesson پایه\|روز\|زنگ\|درس\|معلم\|شروع\|پایان` | افزودن درس به برنامه |
| `/addlearning پایه\|درس\|عنوان\|مهلت\|توضیح` | ثبت تکلیف |
| `/addquestion پایه\|درس\|سؤال\|گزینه۱;گزینه۲\|شمارهٔ پاسخ` | افزودن سؤال آزمون |
| `/setgrade شناسهٔ‌چت\|درس\|عنوان\|نمره\|نمرهٔ‌کل` | ثبت نمره |
| `/broadcast متن` | پیام همگانی |
| `/report` | گزارش مدیریتی |
| `/export` | خروجی JSON از داده‌ها |

### ارسال خودکار (زمان‌بند)
- **هر روز** برنامهٔ روز + تکالیف سررسید (ساعت `daily_send_time`)
- **هر روز** یک سؤال آزمون (ساعت `quiz_send_time`)
- **هفتگی** گزارش مدیریتی برای مدیران
- پنج‌شنبه و جمعه به‌صورت **تعطیل** در نظر گرفته می‌شوند

## 🚀 راه‌اندازی

### ۱) ساخت ربات در تلگرام
در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید، `/newbot` بزنید و **توکن** را بگیرید.
سپس شناسهٔ عددی خودتان را از [@userinfobot](https://t.me/userinfobot) بگیرید (به‌عنوان مدیر).

### ۲) پیکربندی
```bash
cp config.example.json config.json
```
سپس `config.json` را ویرایش کنید:
```json
{
  "bot_token": "توکن ربات شما",
  "admin_ids": [123456789],
  "school_name": "دبیرستان نمونه"
}
```

می‌توانید به‌جای فایل از متغیرهای محیطی هم استفاده کنید:
```bash
export MADRESE_BOT_TOKEN="..."
export MADRESE_ADMIN_IDS="123456789,987654321"
```

### ۳) اجرا
```bash
python -m schoolbot
```

### ۴) اجرای آزمایشی بدون تلگرام
برای امتحان کردن دستورات در ترمینال:
```bash
python -m schoolbot --demo
```
یا با دیتابیس موقت:
```bash
python -m schoolbot --demo --config config.example.json
```

## 🧪 تست‌ها
```bash
pip install pytest

```
۲۳ تست، پوشش: تقویم و روزهای هفته، پارس دستورات، ذخیره‌سازی، جریان آزمون،
کنترل دسترسی مدیر و زمان‌بند.

## 🗂 ساختار پروژه
```
schoolbot/
├── config.py      # بارگذاری تنظیمات (JSON + متغیر محیطی)
├── schedule.py    # تقویم و روزهای هفتهٔ ایرانی
├── storage.py     # لایهٔ SQLite
├── messages.py    # قالب‌بندی پیام‌ها
├── quiz.py        # موتور آزمون
├── handlers.py    # منطق دستورات (توابع خالص و تست‌پذیر)
├── scheduler.py   # ارسال خودکار
├── telegram.py    # کلاینت Bot API + کلاینت جعلی
└── runner.py      # حلقهٔ اصلی long-polling
tests/
├── test_bot.py
└── test_scheduler.py
```

طراحی به‌گونه‌ای است که **منطق دستورات از شبکه جدا** باشد؛ همین باعث می‌شود
کل رفتار ربات بدون اتصال به تلگرام قابل تست باشد.

## ⚙️ نکته‌های عملیاتی
- دیتابیس در `data/school.db` ساخته می‌شود (در `.gitignore` هست).
- برای اجرای همیشگی از `systemd`، `tmux` یا `screen` استفاده کنید.
- زمان‌ها بر اساس `timezone` تنظیمات محاسبه می‌شوند (پیش‌فرض `Asia/Tehran`).
- `tick_seconds` فاصلهٔ بررسی زمان‌بند در حلقهٔ سرویس است (پیش‌فرض ۳۰ ثانیه).
